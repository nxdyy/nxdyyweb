# 产品需求文档 (PRD)

## 项目概述

为 Hexo 博客主题 "hexoThemeKacper" 进行全面重构，实现统一的终端/命令行风格界面设计，并添加完整的主题切换系统。

## 设计理念

### 核心概念
采用 **复古终端美学** 与 **现代交互体验** 的融合设计，打造一个具有强烈视觉辨识度的命令行风格博客界面。

### 设计方向
- **风格定位**: 终端/命令行风格（Terminal/CLI Aesthetic）
- **视觉基调**: 深色背景 + 高对比度文字 + 霓虹强调色
- **交互理念**: 模拟终端操作体验，包含光标闪烁、打字效果、命令行提示符等元素

## 视觉规范

### 字体系统
- **标题字体**: JetBrains Mono / VT323 / Orbitron / Courier Prime / IBM Plex Mono
- **正文字体**: 同标题字体
- **代码字体**: 同标题字体
- **字体大小比例**:
  - 超大标题: 2.5rem (40px)
  - 大标题: 2rem (32px)
  - 中标题: 1.5rem (24px)
  - 小标题: 1.25rem (20px)
  - 正文: 1rem (16px)
  - 小字: 0.875rem (14px)

### 间距系统
- **基础单位**: 4px
- **间距层级**: 4px, 8px, 12px, 16px, 24px, 32px, 48px, 64px
- **容器最大宽度**: 1400px
- **内容区域边距**: 24px (桌面) / 16px (移动)

### 圆角与边框
- **卡片圆角**: 4px (保持硬朗风格)
- **按钮圆角**: 2px
- **输入框圆角**: 0px (纯直角)
- **边框宽度**: 1px
- **强调边框**: 2px

### 阴影系统
- **轻微阴影**: `0 0 10px rgba(var(--color-accent-rgb), 0.1)`
- **中等阴影**: `0 0 20px rgba(var(--color-accent-rgb), 0.2)`
- **强烈阴影**: `0 0 40px rgba(var(--color-accent-rgb), 0.3)`

## 动画效果

### 光标动画
- **类型**: 块状光标 (Block Cursor)
- **闪烁频率**: 1s (ease-in-out)
- **样式**: 与文字等高，使用强调色背景

### 打字效果
- **字符间隔**: 50-100ms
- **缓动函数**: steps(1)
- **触发时机**: 页面加载、标题显示

### 主题切换动画
- **过渡时间**: 300ms
- **缓动函数**: ease-in-out
- **属性**: color, background-color, border-color, box-shadow

### 悬停效果
- **按钮**: 背景色变化 + 轻微发光
- **链接**: 下划线动画 + 颜色变化
- **卡片**: 边框高亮 + 阴影增强

## 交互元素规范

### 按钮
- **样式**: 直角边框，1px 边框宽度
- **背景**: 透明或半透明
- **悬停**: 背景填充 + 发光效果
- **激活**: 内阴影效果

### 输入框
- **样式**: 纯直角，底部边框或全边框
- **背景**: 半透明深色
- **聚焦**: 边框颜色变为强调色
- **占位符**: 使用次要文字色

### 链接
- **默认**: 强调色，无下划线
- **悬停**: 下划线动画 (从左到右展开)
- **已访问**: 降低饱和度

### 滚动条
- **宽度**: 8px
- **轨道**: 透明或与背景同色
- **滑块**: 强调色，圆角 4px
- **悬停**: 滑块变亮

## 组件规范

### 终端窗口组件
```
┌─────────────────────────────────────┐
│ ● ● ●  title                        │
├─────────────────────────────────────┤
│ $ command input                     │
│   output content here               │
│   > nested prompt                   │
└─────────────────────────────────────┘
```

### 代码块
- **背景**: 比主背景稍深的颜色
- **边框**: 1px 实线边框
- **字体**: 等宽字体
- **行号**: 可选，使用次要文字色

### 文章卡片
- **边框**: 1px 实线
- **背景**: 半透明或纯色
- **悬停**: 边框颜色变为强调色

## 响应式断点

- **桌面**: >= 1024px
- **平板**: 768px - 1023px
- **移动**: < 768px

## 技术约束

- 使用 CSS 变量管理主题色
- 支持 localStorage 主题持久化
- 优化动画性能 (使用 transform 和 opacity)
- 确保无障碍访问 (WCAG 4.5:1 对比度)

## 性能要求

- 首屏加载时间 < 3s
- 主题切换无闪烁
- 动画帧率 >= 60fps
- 支持 prefers-reduced-motion
